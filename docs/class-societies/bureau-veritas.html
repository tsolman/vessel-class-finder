Frequently asked questions

How do I check if a ship is classed by Bureau Veritas?

Enter the ship's 7-digit IMO number in the lookup on this page. If Bureau Veritas classes it, the result shows class society BV, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does Bureau Veritas use in IACS data?

BV. The IACS Vessels in Class dataset and this API identify Bureau Veritas (BV) as "BV".

How many ships does Bureau Veritas class?

As of 30 September 2026, the IACS dataset lists 9,958 ships under Bureau Veritas, of which 8,270 are in class (Delivered, Reinstated or Reassigned), 59 suspended and 861 withdrawn. That makes it number 2 of the 12 IACS members by ships listed.

Is this official Bureau Veritas data?

It is Bureau Veritas's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get Bureau Veritas class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
