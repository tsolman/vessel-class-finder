Check ClassNK class status through the API

Send IMO numbers to /vessels. Ships classed by ClassNK come back with "class": "NKK":

curl -X POST https://vessel-class-finder-production.up.railway.app/vessels \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"imos": [9321483, 9074729]}'

Filter the response on class == "NKK" to find the ClassNK-classed ships in a list, and on status to find any that are suspended or withdrawn.

Frequently asked questions

How do I check if a ship is classed by ClassNK?

Enter the ship's 7-digit IMO number in the lookup on this page. If ClassNK classes it, the result shows class society NKK, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does ClassNK use in IACS data?

NKK. The IACS Vessels in Class dataset and this API identify Nippon Kaiji Kyokai (ClassNK) as "NKK".

How many ships does ClassNK class?

As of 30 September 2026, the IACS dataset lists 10,117 ships under ClassNK, of which 9,009 are in class (Delivered, Reinstated or Reassigned), 74 suspended and 967 withdrawn. That makes it number 1 of the 12 IACS members by ships listed.

Is this official ClassNK data?

It is ClassNK's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get ClassNK class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
