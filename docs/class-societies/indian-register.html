Frequently asked questions

How do I check if a ship is classed by Indian Register of Shipping?

Enter the ship's 7-digit IMO number in the lookup on this page. If Indian Register of Shipping classes it, the result shows class society IRS, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does Indian Register of Shipping use in IACS data?

IRS. The IACS Vessels in Class dataset and this API identify Indian Register of Shipping (IRS, IRClass) as "IRS".

How many ships does Indian Register of Shipping class?

As of 30 September 2026, the IACS dataset lists 1,639 ships under Indian Register of Shipping, of which 1,154 are in class (Delivered, Reinstated or Reassigned), 55 suspended and 429 withdrawn. That makes it number 9 of the 12 IACS members by ships listed.

Is this official Indian Register of Shipping data?

It is Indian Register of Shipping's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get Indian Register of Shipping class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
