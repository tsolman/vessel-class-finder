Check Korean Register class status through the API

Send IMO numbers to /vessels. Ships classed by Korean Register come back with "class": "KR":

  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"imos": [9321483, 9074729]}'

Frequently asked questions

How do I check if a ship is classed by Korean Register?

Enter the ship's 7-digit IMO number in the lookup on this page. If Korean Register classes it, the result shows class society KR, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does Korean Register use in IACS data?

KR. The IACS Vessels in Class dataset and this API identify Korean Register (KR) as "KR".

How many ships does Korean Register class?

As of 30 September 2026, the IACS dataset lists 2,559 ships under Korean Register, of which 1,589 are in class (Delivered, Reinstated or Reassigned), 68 suspended and 283 withdrawn. That makes it number 8 of the 12 IACS members by ships listed.

Is this official Korean Register data?

It is Korean Register's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get Korean Register class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
