Frequently asked questions

How do I check if a ship is classed by Lloyd's Register?

Enter the ship's 7-digit IMO number in the lookup on this page. If Lloyd's Register classes it, the result shows class society LRS, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does Lloyd's Register use in IACS data?

LRS. The IACS Vessels in Class dataset and this API identify Lloyd's Register (LR) as "LRS".

How many ships does Lloyd's Register class?

As of 30 September 2026, the IACS dataset lists 7,606 ships under Lloyd's Register, of which 7,182 are in class (Delivered, Reinstated or Reassigned), 95 suspended and 318 withdrawn. That makes it number 5 of the 12 IACS members by ships listed.

Is this official Lloyd's Register data?

It is Lloyd's Register's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get Lloyd's Register class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
