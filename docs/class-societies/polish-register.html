Frequently asked questions

How do I check if a ship is classed by Polish Register of Shipping?

Enter the ship's 7-digit IMO number in the lookup on this page. If Polish Register of Shipping classes it, the result shows class society PRS, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does Polish Register of Shipping use in IACS data?

PRS. The IACS Vessels in Class dataset and this API identify Polish Register of Shipping (PRS, Polski Rejestr Statków) as "PRS".

How many ships does Polish Register of Shipping class?

As of 30 September 2026, the IACS dataset lists 608 ships under Polish Register of Shipping, of which 439 are in class (Delivered, Reinstated or Reassigned), 31 suspended and 138 withdrawn. That makes it number 10 of the 12 IACS members by ships listed.

Is this official Polish Register of Shipping data?

It is Polish Register of Shipping's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get Polish Register of Shipping class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
