Check RINA class status through the API

  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"imos": [9321483, 9074729]}'

Frequently asked questions

How do I check if a ship is classed by RINA?

Enter the ship's 7-digit IMO number in the lookup on this page. If RINA classes it, the result shows class society RINA, the class status and the last and next survey dates. For many ships at once, use the API with up to 100 IMO numbers per request.

What code does RINA use in IACS data?

RINA. The IACS Vessels in Class dataset and this API identify RINA (Registro Italiano Navale) as "RINA".

How many ships does RINA class?

As of 30 September 2026, the IACS dataset lists 5,842 ships under RINA, of which 4,307 are in class (Delivered, Reinstated or Reassigned), 61 suspended and 783 withdrawn. That makes it number 6 of the 12 IACS members by ships listed.

Is this official RINA data?

It is RINA's own data as published by IACS in its Vessels in Class dataset, refreshed weekly. It is not a substitute for class certificates or the society's own records, which remain authoritative.

Can I get RINA class status through an API?

Yes. POST a list of IMO numbers to /vessels with your API key and each result includes the class society code, status, survey dates and reason for the latest status change. The free tier includes 100 lookups a month.
