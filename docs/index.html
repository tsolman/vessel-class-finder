FAQ

    
Frequently asked questions

    

      

        Is there an API for IACS vessel classification data?
        
IACS publishes its Vessels in Class data only as a downloadable ZIP/CSV file, not as an API. Vessel Class Finder scrapes that file weekly and serves it as a JSON REST API: POST a list of IMO numbers to /vessels with an x-api-key header and get each ship's classification society, class status and survey dates back.

      

      

        How do I check a ship's class status by IMO number?
        
Register for a free API key, then send POST /vessels with body {"imos": [9200079]}. The response includes the classification society (for example DNV, LR, BV, ABS, ClassNK), the class status (In Class, Suspended, Withdrawn), the last and next survey dates, and the reason for the latest status change.

      

      

        Which classification societies are covered?
        
All vessels listed in the IACS Vessels in Class dataset, which covers ships classed by IACS member societies such as ABS, BV, CCS, CRS, DNV, IRS, KR, LR, ClassNK, PRS, RINA and TL.

      

      

        How often is the data updated?
        
The dataset is re-downloaded from IACS every Sunday and swapped in atomically, so the API never serves a partial refresh.
