Vessel class checks for sanctions and KYC screening

Data from the IACS Vessels in Class dataset, as of 30 September 2026. Refreshed weekly.

A vessel's classification status is a useful risk indicator in sanctions and KYC screening. A withdrawn or suspended class, a transfer to a non-IACS society, or no IACS record at all are patterns that often deserve a closer look. Vessel Class Finder returns this data by IMO number from the IACS Vessels in Class dataset. It does not match names against sanctions lists, so use it alongside your screening tool.

Why class status matters for compliance teams

Most large commercial ships are classed by one of the 12 IACS members. A vessel that leaves IACS class, or loses class, has changed something about how it is surveyed and insured. That is not proof of wrongdoing. It is a reason to ask questions.

Compliance teams commonly treat these as risk indicators, alongside other signals of dark fleet or shadow fleet activity:

  • Class withdrawn or suspended, especially with a reason such as Survey overdue or Non-compliance with conditions of class.
  • Class moved with the reason Transfer of class to a non-IACS society.
  • A recent status change on an older vessel.
  • No IACS record at all for a vessel that trades internationally.

Class data does not replace sanctions list matching, ownership research or AIS analysis. It adds one more independent data point to the file.

Workflow: screen a vessel or a list of vessels

  1. Collect the IMO numbers for the vessels in the deal, cargo or counterparty portfolio.
  2. Send them to POST /vessels with your x-api-key header and a body like {"imos":["9074729","9321483"]}. One request takes up to 100 IMOs.
  3. Check status and reason_for_status for each result.
  4. Flag any vessel with Withdrawn, Suspended, or a reason of Transfer of class to a non-IACS society.
  5. Flag any IMO that returns no record. Absence from the dataset means the vessel is not classed by an IACS member, which is worth checking.
  6. Record date_of_latest_status and the date you ran the check in your case file. Then route flagged vessels to enhanced due diligence and ask for the class certificates from the society.

You can also try a single IMO first with the free lookup box on the site. No signup is needed.

Fields and statuses to check

Each record has imo, vessel_name, class, status, date_of_survey, date_of_next_survey, date_of_latest_status and reason_for_status. Dates are DD/MM/YYYY strings.

  • Withdrawn (4,848 vessels): the society no longer classes the vessel. Read the reason. Scrapping and transfer are common. Non-compliance and owner's request are more worth a question.
  • Suspended (575): class is not currently in force. Treat as a higher risk indicator until reinstated.
  • Reinstated (3,381): class was restored after a suspension or withdrawal. Check how long the gap lasted using date_of_latest_status.
  • Reassigned (1,382): class was reassigned, for example after a transfer. Check the class code to see who holds it now.
  • Delivered (46,063): the vessel entered class with this society and is currently classed.
  • No status: some rows (3,974) have no status. Treat these as needing a manual check.

date_of_latest_status and date_of_next_survey give you dates to cite in a review. A next-survey date in the past on a vessel that is still trading is a flag on its own.

What this data does not cover

The data comes from IACS's public Vessels in Class dataset. It is refreshed weekly, every Sunday. It is not a substitute for official class records or certificates from the society.

It covers only IACS-classed vessels. Ships classed by non-IACS societies, or with no class, will not appear. That absence is a signal, but it is not evidence of sanctions evasion by itself. Use it to decide where to look next.

The API does not screen names or IMOs against sanctions lists. It provides class data that complements the tools you already use.

Frequently asked questions

Is a vessel's class status a sanctions red flag?

It can be an indicator, not proof. Withdrawn or suspended class, or a transfer to a non-IACS society, are patterns compliance teams often treat as a reason for enhanced due diligence. Combine them with ownership, voyage and sanctions list checks.

Does Vessel Class Finder check vessels against sanctions lists?

No. It returns classification data from the IACS Vessels in Class dataset by IMO number. Use it alongside a sanctions screening tool.

What does it mean if an IMO number is not found?

The vessel is not in the IACS Vessels in Class dataset. It may be classed by a non-IACS society or have no class. This is worth checking with the owner or manager, and by asking for class certificates.

Can I screen a whole list of vessels at once?

Yes. Send up to 100 IMO numbers in one POST /vessels request. Each IMO counts as one lookup against your monthly allowance.

How do I keep an audit trail of a class check?

Store the API response with the date you ran it. The response includes date_of_latest_status, date_of_survey and date_of_next_survey, which show the class position at the time. The dataset refreshes weekly.
